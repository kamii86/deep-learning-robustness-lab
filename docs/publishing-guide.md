# Работа с репозиторием и воспроизведение экспериментов

## О проекте

**Deep Learning Robustness Lab** — исследовательский проект на PyTorch, посвящённый реализации алгоритмов глубокого обучения, обучению свёрточных нейронных сетей и исследованию их устойчивости к adversarial-атакам.

Репозиторий содержит выполненные эксперименты, обученные модели, метрики, графики и документацию.

**Основные результаты:**
- ResNet-20 на CIFAR-10 — 83,05% test accuracy.
- PGD-AT на FashionMNIST — 70,40% accuracy при PGD-20, ε = 0,1.
- Исследованы PGD-L∞, PGD-L2, targeted PGD и L0-атаки.
- Проведены эксперименты по Edge of Stability и Catastrophic Overfitting.
- Сохранены 16 визуализаций экспериментов.

## 1. Организация репозитория

В проекте используются две основные ветки.

### `main` — основная ветка портфолио

Содержит:
- `README.md` — описание проекта и ключевые результаты;
- `figures/` — галерею экспериментальных графиков;
- `docs/` — методологию, результаты и документацию;
- `.github/workflows/validate.yml` — автоматическую проверку проекта.

Эта ветка предназначена для публичного представления проекта.

### `submission/hw1` — реализация и сдача задания

Содержит полный код и экспериментальные результаты:

- `hw1.ipynb` — выполненный Jupyter Notebook;
- `artifacts/metrics.json` — метрики экспериментов;
- `artifacts/resnet20.pt` — веса ResNet-20;
- `artifacts/fashion_standard.pt` — веса стандартной CNN;
- `artifacts/fashion_pgd_at.pt` — веса защищённой CNN;
- `scripts/check_submission.py` — скрипт проверки комплектности работы.

[Открыть ноутбук](https://github.com/kamii86/deep-learning-robustness-lab/blob/submission/hw1/hw1.ipynb)

После проверки и объединения Pull Request эти файлы также появятся в основной ветке.

До завершения проверки преподавателем PR остаётся открытым. Комментарии и замечания сохраняются в истории обсуждения.

## 2. Как воспроизвести результаты

Для работы с полной реализацией необходимо получить ветку `submission/hw1`.

```bash
git clone -b submission/hw1 https://github.com/kamii86/deep-learning-robustness-lab.git
cd deep-learning-robustness-lab
```

Проверить комплектность проекта:

```bash
python3 scripts/check_submission.py
```

Скрипт проверяет наличие обязательных файлов, сохранённые результаты ноутбука и основные метрики. Повторного обучения нейросетей не требуется.

Для воспроизведения экспериментов с нуля можно открыть `hw1.ipynb` в Google Colab, подключить GPU и выполнить ячейки последовательно.

Для полного режима используется:

```python
FAST_MODE = False
```

Эксперименты включают обучение на CIFAR-10 и FashionMNIST. Повторное выполнение может потребовать значительных вычислительных ресурсов.

## 3. Автоматическая проверка

В проекте используется GitHub Actions.

Workflow `validate.yml` предназначен для проверки структуры репозитория, документации и сохранённых результатов экспериментов.

Автоматическая проверка не выполняет повторное обучение моделей и не требует GPU.

## 4. Внесение изменений

Изменения в документацию и визуализации вносятся в `main` либо через отдельный Pull Request.

Для обновления кода используется отдельная рабочая ветка. После внесения изменений выполняются локальные проверки, создаётся коммит и открывается Pull Request.

Рекомендуемый стиль сообщений коммитов:

- `feat:` — новая функциональность;
- `fix:` — исправление ошибок;
- `docs:` — документация;
- `test:` — тесты;
- `ci:` — автоматические проверки;
- `refactor:` — изменение структуры кода без изменения поведения.

Изменения в обученных моделях должны сопровождаться обновлением соответствующих метрик и результатов экспериментов.

## 5. Завершение проверки

После получения замечаний преподавателя необходимые исправления вносятся в ветку `submission/hw1`.

После завершения проверки Pull Request можно объединить с `main`.

Затем следует обновить ссылки на ноутбук и файлы моделей, используя относительные пути внутри основной ветки, и проверить успешное выполнение GitHub Actions.

Таким образом, основная ветка станет самостоятельным воспроизводимым ML-проектом, пригодным для демонстрации в портфолио.
