# PR title

ДЗ2: NER на Few-NERD — BERT-Mini, анализ ошибок и четыре бонуса

# Description

Добавлен вариант NLP ДЗ2: предобученный BERT-Mini дообучается на фиксированном
подмножестве Few-NERD supervised (8000/1500/1500).
Реализованы IO→BIO и выравнивание сабвордов, подсчет параметров по блокам,
словарный бейзлайн, обучение, entity/token F1, категории ошибок и абляция заморозки.

В notebook сохранены outputs полного запуска с `FAST_MODE=False`.
На validation F1 дообученной модели 0.6531 против 0.2033
у словаря; на test micro F1 0.6603, macro F1 0.5881.
Это результат на выбранном подмножестве, а не на полном официальном test Few-NERD.

Бонусы 6.2–6.5: BERT-Tiny, регистр/опечатки, динамическая INT8-квантизация и
precision–recall по порогам mean/min. 6.1 не выбран.
Модели Apache-2.0, Few-NERD CC BY-SA 4.0; источники и SHA указаны в notebook/README.

Проверка: последовательный запуск всех 49 code cells в свежем IPython,
быстрый прогон, сохранение всех 44 исходных assert и сигнатур, 2000 round-trip тестов,
проверка JSON, alignment, точных повторов, метрик и монотонности recall.
Артефакты и графики приложены; датасет, runs и веса исключены.

Ограничения: один seed, CPU, компактная uncased-модель, IO-неоднозначность границ,
усечение и ограниченный размер подмножества. Настройки и пороги выбирались по validation.
